Frozen payouts

A winner is never frozen. A run's payout is frozen only if it's more than that run could possibly win from the prize table (a bug or a break-in, not luck). Check it, then Release sends it to the player's wallet on the next payout pass.

None frozen.

Weekly modes

One weekly mode runs a game week (from Sunday 9 PM Indiana time), taking turns among the ones switched on. All off: no weekly mode, everyone plays normal Free-for-all. A change reaches new games within a minute. Each switch is signed by your wallet and written to the public log.

Claim rewards

Reward tokens sent to SANTA holders (GP, GLDX, any other) land in the Game pool, the old Slots pool and the Lottery wallets. Claiming sends every token in those three wallets that is NOT SANTA to the treasury. SANTA is never touched and nothing can be sent anywhere else. The payout worker sends them within a minute; each pool pays a tiny one-time fee the first time the treasury receives a new token.

Possible bots

Private to this screen (your wallet signs the check; it isn't logged or shown anywhere public).

Send that SANTA from your own wallet to the pool's address, then paste the transaction's signature here. The server checks it on the chain and books exactly what arrived (after SANTA's 3% tax). Extra SANTA is simply added to the pool.
